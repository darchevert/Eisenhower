# Assets requis

Avant de publier, remplacer ces fichiers par les vraies icônes de l'app :

| Fichier | Taille | Usage |
|---------|--------|-------|
| `icon.png` | 1024×1024 | Icône principale Play Store |
| `adaptive-icon.png` | 1024×1024 | Icône adaptative Android (fond blanc recommandé) |
| `splash-icon.png` | 1284×2778 | Écran de chargement |
| `favicon.png` | 32×32 | Web uniquement |

## Outils pour créer les icônes
- **Figma** : créer le design, exporter en PNG
- **Canva** : templates d'icônes d'apps
- **app-icon.co** : générateur automatique depuis une image 1024×1024
- Claude Code peut générer une description pour Midjourney/DALL-E si nécessaire
